# Banking Where You Are — Mobile Journalism Campaign

A student-created academic website concept for the Mobile Journalism module (H2612CJ), built around **“Banking Where You Are — Your bank. Your life. Your way.”**

## Campaign website contents

- Campaign overview and project attribution.
- Campaign identity, tone, visual direction and key messages.
- Campaign aim, target audience and objectives.
- Digital-banking safety and customer-trust messaging.
- Twelve campaign asset concepts with specifications and creative rationale.
- A 45-second mobile video concept, production script and storyboard.
- Student project contact and an academic-use notice.

## Development

Requires Node.js and npm.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
```

## Academic-use notice

This is an independent student-created educational concept for Mobile Journalism (H2612CJ). It is not an official Bank Windhoek website or service. It does not collect banking credentials or provide banking transactions. The asset gallery presents visual concepts for the assignment; the listed filenames are suggested output names, not downloadable files supplied by this website. Product references and service descriptions should be checked against verified sources before being used for public-facing banking communication.
