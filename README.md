# Banking Where You Are — Mobile Journalism Campaign

A student-created academic website concept for the Mobile Journalism module (H2612CJ), built around the campaign **“Banking Where You Are — Your bank. Your life. Your way.”**

## Campaign website contents

- Campaign overview and project attribution.
- Campaign identity, tone, visual direction and key messages.
- Campaign aim, target audience and objectives.
- Digital banking safety and customer-trust messages.
- Campaign creative assets and asset inventory.
- 45-second mobile video concept with production script and storyboard.
- Student project contact and academic disclosure.

## Development

Requires Node.js and npm.

\`\`\`sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
\`\`\`

## Academic-use notice

This is an independent student-created educational prototype for Mobile Journalism (H2612CJ). It is not an official Bank Windhoek website or service, and it does not collect banking credentials or provide banking transactions. Campaign statements and product references are part of the student assignment concept.
