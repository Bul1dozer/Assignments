# Bank Windhoek — Banking Where You Are

An academic website prototype for the Mobile Journalism module (H2612CJ). The site combines a corporate-style banking homepage with a dedicated **Banking Where You Are** communication campaign.

## Features

- Responsive, banking-style navigation and homepage.
- Personal, business, corporate and digital banking information pages.
- Campaign portfolio for the original Mobile Journalism assignment.
- Selected banking news summaries linked to Bank Windhoek's public newsroom.
- Customer-safety messaging and direct links to official information.
- A clear academic-project notice; no account login, credential collection or banking transactions.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

## Important note

This is an independent student-created academic prototype. It is not operated, maintained or endorsed by Bank Windhoek and must not be used to enter account details or perform banking transactions. Verify current product details, fees, eligibility and security guidance through the official Bank Windhoek website.
